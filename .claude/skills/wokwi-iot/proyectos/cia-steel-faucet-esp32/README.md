# Cia Steel Faucet (Moen, inc.) - ESP32 prototype

Wokwi project: https://wokwi.com/projects/481155523220429825

OOP prototype based on ModestIoT: HC-SR04 proximity sensor, blue LED and a relay
that opens the water valve for 5 s when hands get closer than 10 cm. The console
reports distance (cm) and valve state every 2.5 s.

Files: `sketch.ino`, `CiaSteelFaucetDevice.h`, `UltrasonicSensor.h`,
`DigitalActuator.h`, `ModestIoT.h`, `diagram.json`, `libraries.txt`.
